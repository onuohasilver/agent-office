Hire a team of Claude Code agents. Watch them work.

A 3D office where the staff are Claude Code agents. Hand someone a job and they walk to a desk and do it for real, in your project folder.

Get started View on GitHub
npm install -g agent-office-studio

A team, not a queue

Every job is a real claude process in your project. The office just makes it something you can see and steer.

You chat; the office does the rest

@Ada #storefront fix the checkout bar goes straight to Ada. Anything untagged goes to the chief of staff, who works out the project and who's free.

Real work, visibly

Agents walk to the library to read, the server room to run commands and their desk to write. Each job's drawer shows its log, model and exactly which files changed.

You stay in charge

Pick clearance per job: plan only, edit files, or full autonomy. The chief picks Haiku, Sonnet or Opus to fit the work and steps up when a job fails.

Agents talk to each other

They message colleagues mid-task, hand work to whoever is free, hold a 9:30 standup and use Slack-style channels. When idle, they play pool in the break room.

Talk to it

Dictate with whisper.cpp and hear replies in a different voice per agent, all on your machine.

Yours, on your machine

It listens on localhost only. Use it on your Claude plan or with an API key.

Up and running in a minute

You need Node.js 20+, git, and Claude Code signed in on this machine (or an Anthropic API key).

  1. Install

    One global package.

    npm install -g agent-office-studio

  2. Point it at your projects

    Run it from the folder whose subfolders are your projects.

    cd ~/projects
agentoffice

  3. Hand out a job

    Open the URL it prints (default localhost:4317) and say what you need.

    @Ada #storefront fix the checkout bar
